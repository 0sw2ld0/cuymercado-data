CuyMercado · distribución pública de datos
Repositorio: https://github.com/0sw2ld0/cuymercado-data
Código: repositorio privado independiente.

Este repositorio está reservado para archivos validados: current.json, releases/<sha256>/pack.json y cabeceras de caché. La publicación requiere confirmar las condiciones de redistribución de las fuentes. No contiene claves, código de iOS ni archivos originales de las entidades.

current.json identifica el paquete por fecha de corte, versión de esquema, tamaño y SHA-256. Cada precio conserva fuente, fecha y unidad. La fecha de publicación no implica que los precios sean del día. No se considera una fuente oficial independiente.
